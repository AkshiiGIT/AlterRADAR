# AlterRADAR v0.7.0 — Simplification de la recherche

- Import du CV et de la lettre au démarrage ; analyse de profil déclenchée après import.
- Confirmation du profil puis scan immédiat de toutes les sources actives.
- Surveillance horaire possible dès l’accueil.
- Réglages de sources avancés repliés par défaut, sans URL d’entreprise à saisir.
- Nouvelle source **Alternances Tech France (communauté)** : lecture d’une liste GitHub publique, **pas une API officielle** ; couverture tech limitée, annonces potentiellement périmées ; filtre Bac+N et écoles privées toujours appliqué.
- Maintien des 30 détecteurs d’ATS et des connecteurs existants.
- Correction de la documentation, diagnostics et tests.

Ce ZIP est une version de **développement**, sans installeur natif compilé ; les APIs distantes et Telegram nécessitent des tests réels.
